# كلية الأفق الأكاديمية | Al-Ufuq College
> **بوابة إلكترونية جامعية متكاملة ومربوطة بقاعدة بيانات MySQL (XAMPP)**

نظام متكامل وشامل لكلية الأفق مصمم بأحدث معايير تجربة المستخدم (UI/UX) لدعم بيئة تعليمية محفزة وملهمة للطلاب ورواد العلم.

---

## 🌟 الميزات الرئيسية للنظام

1. **التقديمات للكلية لبداية العام (Admissions)**:
   - استمارة إلكترونية شاملة للالتحاق بالعام الجامعي 2026/2027.
   - التحقق الفوري من مسار الثانوية (علمي/أدبي) ومطابقة النسبة مع الحد الأدنى للقسم.
   - توليد رقم استمارة فريد (`OFQ-2026-XXXX`) وإشعار قبول فوري قابل للطباعة.

2. **عرض نتائج القبول (Admission Results)**:
   - محرك بحث بالاسم أو رقم الاستمارة أو رقم الجلوس أو الرقم الوطني.
   - بطاقة إشعار قبول رسمية توضح حالة القبول (مقبول نهائياً، مقبول مبدئياً، قيد المراجعة).
   - إحصائيات شفافة وقائمة فورية لآخر المقبولين.

3. **الأقسام العلمية والأدبية (Academic Departments)**:
   - **قسم التمريض (علمي)**: بكالوريوس علوم التمريض، تدريب سريري متقدم.
   - **قسم طب ومختبرات (علمي)**: بكالوريوس المختبرات الطبية والتشخيص الجزيئي.
   - **قسم تقنية معلومات (علمي)**: بكالوريوس IT، برمجيات، ذكاء اصطناعي وأمن سيبراني.
   - **قسم إدارة الأعمال (مشترك)**: بكالوريوس إدارة وريادة أعمال وتسويق رقمي.
   - **قسم لغات وترجمة - إنجليزي (مشترك)**: بكالوريوس لغة إنجليزية وترجمة فورية وتحريرية.
   - **قسم نظم معلومات محاسبية (مشترك)**: بكالوريوس AIS، أنظمة ERP وتقنيات مالية (FinTech).

4. **التقويم الدراسي الأكاديمي (Academic Calendar)**:
   - خط زمني تفاعلي لمواعيد التقديم، بداية الدراسة، فترات الحذف والإضافة، الامتحانات النصفية والنهائية، والفعاليات.

5. **نتائج الامتحانات وكشوف الدرجات (Exam Results & Transcripts)**:
   - استعلام برقم القيد الجامعي (`STD-2026-101`) أو رقم الجلوس.
   - كشف درجات رسمي معتمد يحسب المعدل الفصلي والتراكمي (GPA من 4.00) والتقدير العام والختم الجامعي، وقابل للطباعة بضغطة زر.

6. **النشاط الطلابي والحياة الجامعية (Student Activities)**:
   - **المبادرات الطلابية**: مبادرة "أفق العطاء"، نادي المطورين البرمجي "Horizon Dev Club".
   - **دورات كرة القدم**: بطولة كأس الأفق لخماسيات كرة القدم، جدول المباريات الحية والنتائج والفرق.
   - **الأيام الثقافية**: معارض التراث والحضارات، المسابقات الشعرية والفنون.
   - **الحملات التوعوية**: حملة الفحص الميداني للدم والسكري، أسبوع التوعية بالأمن الرقمي.
   - **المشاركات الطلابية**: هاكاثونات ومؤتمرات علمية وفرق تطوعية.
   - نموذج انضمام وتسجيل فوري للطلبة في أي نشاط.

7. **بوابات تسجيل ودخول منفصلة (Dual Portals)**:
   - **بوابة الطالب (`student_dashboard.php`)**: للملف الأكاديمي، كشوف الدرجات، متابعة الأنشطة، وتذاكر الشكاوى.
   - **لوحة تحكم إدارة الكلية والكنترول (`admin_dashboard.php`)**: لمعالجة طلبات القبول، رصد الدرجات، الرد على الشكاوى، وإدارة الأنشطة والبطولات.
   - إمكانية إنشاء حساب طالب جديد (`register.php`).

8. **نظام استعلامات الكلية والمساعد الذكي (Smart Inquiries & FAQ)**:
   - قاعدة معرفية فورية للأسئلة الشائعة مع محرك بحث وأقسام مفصلة.
   - مساعد تفاعلي ذكي عائم (Chatbot) يجيب فورياً على أسئلة الطلاب حول الشروط والتخصصات.
   - نموذج إرسال استفسار مباشر للإدارة.

9. **الشكاوى الطلابية والمقترحات (Complaints & Suggestions)**:
   - تقديم شكوى أو مقترح مع خيار إخفاء الهوية للخصوصية.
   - رقم تتبع فريد (`TKT-2026-XXXX`) ومتابعة حالة التذكرة ورأي الإدارة.
   - لوحة الشفافية لعرض الإجراءات المتخذة على مقترحات الطلبة.

10. **تصميم ظريف ومحفز للطلاب**:
    - عبارات تشجيعية متجددة في الواجهة والهيدر تزرع الحماس والإلهام.
    - ألوان متناسقة، خطوط عربية أنيقة (Tajawal & Cairo)، وأيقونات جذابة.

## 🛠️ متطلبات التشغيل عبر تطبيق XAMPP

1. تشغيل تطبيقي **Apache** و **MySQL** من لوحة تحكم XAMPP Control Panel.
2. وضع مجلد المشروع داخل:
   ```
   C:\xampp\htdocs\alufuq-college\
   ```
3. تم إنشاء قاعدة البيانات واستيرادها تلقائياً باسم: `alufuq_college`.
   (أو يمكنك استيراد الملف يدوياً من: `sql/database.sql` عبر phpMyAdmin).
4. فتح الموقع عبر المتصفح:
   ```
   http://localhost/alufuq-college/
   ```
